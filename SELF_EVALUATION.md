# Self-Evaluation

## 📝 Half-Page Summary
This project is a simple Task Management Dashboard built with Angular. It supports CRUD operations and allows users to move tasks across "To Do", "In Progress", and "Done" columns using drag-and-drop (Angular CDK). The UI is clean and responsive. While the application meets functional requirements, improvements can be made in backend integration and state persistence.

## 👀 Self-Criticism
- No backend or database used; tasks reset on refresh.
- Lack of reusable components for task form/modal.
- No unit testing or validation logic implemented.
- Error handling is minimal.

## ⏳ Improvements (If I had more time)
- Integrate a backend with REST APIs for full CRUD persistence.
- Add form validation and error handling.
- Implement user authentication.
- Write unit tests and use state management (e.g., NgRx) for scalability.
- Polish UI with more animations and transitions.
